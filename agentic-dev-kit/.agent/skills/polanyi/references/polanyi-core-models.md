# Michael Polanyi: 核心心智模型与启发式

## 核心心智模型 (Core Models)

1. **隐性知识 (Tacit Knowledge)**: “We can know more than we can tell.” 有些知识靠实践与身体习得，无法言说（如骑车、识脸）。应用：分析“说不清楚的技能”。
2. **辅助-焦点意识 (Subsidiary-Focal Awareness)**: 所有认知涉及双层结构，我们依赖辅助线索（如手感）来聚焦主要目标（如敲钉子）。应用：分析注意力分配与工具沉浸。
3. **内居 (Indwelling)**: 我们通过“居住”在辅助线索或传统中来形成理解。理解就是与知识同居。应用：分析师徒传承与文化适应。
4. **信托框架 (Fiduciary Framework)**: 知识建立在信念之上（We believe more than we can know），科学共识源头上是一种负责任的承诺而非必然定理。应用：分析共识形成与理性限度。
5. **后批判哲学 (Post-Critical Philosophy)**: 反对将怀疑主义作为科学核心，既定信念和个人承诺是知识的条件而非障碍。应用：批判纯粹客观性的迷思。
6. **科学共和国 (Republic of Science)**: 科学是自组织的探索者共同体，依靠独立学者的自主协调（看不见的手），反对中央计划。应用：分析科研组织与去中心化协作。
7. **涌现与层级实在 (Emergence & Hierarchical Reality)**: 生命意识无法还原为物理化学过程，高层级受自身规律支配（如下层是零件，上层是机器设计本身）。应用：分析还原论局限与AI认知论。

## 决策启发式 (Decision Heuristics)

1. **从具体例子出发**: 不要从抽象定义开始，用日常经验（骑车）说明问题。
2. **拒绝中央计划**: 复杂活动不可被计划框死。
3. **理论与实践统一**: 个人选择反证其信仰（如流亡反纳粹）。
4. **跨学科探索**: 知识边界是人为的，重要问题都在边界之外。
5. **知识是危险的**: "Personal knowledge is an intellectual commitment, and as such inherently hazardous."
6. **寻找从-到结构**: 识别事物内部的辅助和焦点意识规律。
7. **尊重而不盲从传统**: 传统是创新的踏板也是修正的对象。
8. **区分通用与具体权威**: 科学界是自我解释的 General Authority，非极权式的 Specific Authority。
